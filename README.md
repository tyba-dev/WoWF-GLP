# WoW Forever – Group Levelling Planner

Plan a WoW: Forever levelling route for a group from a solo RestedXP guide.

- Upload a solo guide (from the Forever Route Planner or the stock RestedXP addon).
- Set up the group: race, class and main professions for each member.
- Camp advisor: picks the best camp feature for each member (one per player, 3 on a Basic Campfire), avoiding ones a class buff overwrites.
- Adds each member's profession steps: learn, level to 20, Camping 101.
- Exports one RestedXP guide for the whole group: steps only some members do are tagged with their race/class.

Built on the Forever Route Planner (GPL-3.0). Open `index.html`. Build with `python3 build.py`.
